# Vectors examples

`vectors-overview.ipe` is the editable 13-page source used by the first five Vectors presentation boards. Every computed component, resultant, and difference was created through the standalone Vectors ipelet in a real Ipe 7.2.30 session.

The document contains:

- Cartesian components in the default axes and in rotated active axes;
- positive and negative decomposition in arbitrary selected directions;
- source inference when a direction is primary and when all three selections are arrowed;
- tail-to-tail, head-to-tail, directed-chain, and connected non-chain resultants;
- common-tail, common-head, and ordered three-vector subtraction with different primary selections.

`vectors-inclined-plane.ipe` is a separate editable application of the current-axes command. Its active x-axis points down the slope and its active y-axis points perpendicular into the plane, so the selected vertical weight is decomposed into exact down-slope and inward-normal components. The inclined plane uses Ipe's `gray`, the block uses `lightgray`, and `mark/disk(sx)` identifies the block center.

The six PNG presentation boards under `../docs/images/` use renders from these two sources. Titles, legends, and panel layout are added around the Ipe renders; the geometric content is not replaced by generated illustrations or SVG stand-ins.
