# Circles examples

This directory contains the editable Ipe source used for the Circles presentation:

- `circles-overview.ipe`: a two-stage tangent-circle workflow showing all eight candidates and the result selected by the user.

The corresponding SVG, PNG, and real Ipe canvas screenshots live under `../docs/images/`. Open the `.ipe` file to inspect, restyle, or modify every object.

The document embeds only the official `basic` stylesheet and a small self-contained presentation stylesheet. It does not contain the author's personal preamble or unrelated symbol libraries.
