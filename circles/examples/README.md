# Circles examples

This directory contains the editable Ipe source used for the Circles visual guide:

- `circles-overview.ipe`: a 23-page gallery covering the eight-candidate tangent-circle workflow, inversion and radical constructions, tangent lines, the remaining tangent-circle constraint sets, and the transformed-ellipse center.

The five presentation boards under `../docs/images/` use renders from this document. Open the `.ipe` file to inspect, restyle, or modify every geometric object.

The document embeds the complete style definitions it needs, including the `semithick` and `normal` pens used by the gallery. It does not depend on the author's personal preamble or an external style file.
