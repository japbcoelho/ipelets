# Conics examples

This directory contains the editable Ipe source used for the Conics presentation:

- `conics-overview.ipe`: a multi-page document covering a conic through five points, extracted property guides, focus-directrix construction, compact hyperbola branches, and multiple exact parabolas.
- `conics-feature-gallery.ipe`: a 32-page acceptance gallery covering every construction family, advanced feature workflows, explicit degenerate loci, transformed objects, fit-and-replace, inspection, and metadata revalidation.

Open either `.ipe` file to inspect, restyle, or modify every path, mark, guide, label, and group.

The documents use only Ipe's official basic definitions plus styles embedded directly in each file. They do not require the author's personal preamble, symbolic names, or external style files.
