# Triangles examples

Open `triangles-feature-gallery.ipe` in Ipe to inspect the editable source for every PNG used in the documentation. All seven pages were created through the standalone Triangles runtime, not redrawn as SVG illustrations.

Source triangles use the `semithick` pen and construction segments use the `normal` pen throughout the gallery.

The document contains:

- fundamental centers and the Euler line from one selected triangular path;
- center-specific defining lines;
- contact, Gergonne, and Nagel geometry;
- the nine-point circle and its nine named points;
- pedal and Cevian constructions from a selected reference point;
- isogonal and isotomic conjugates;
- Brocard, isogonic, isodynamic, symmedian, and Napoleon centers.

The labels `A`, `B`, and `C` in the gallery are explanatory text. The ipelet itself needs only the selected triangle and does not insert helper vertex marks.
